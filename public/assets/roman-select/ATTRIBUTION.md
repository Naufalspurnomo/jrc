# Roman Selection Image Attribution

The six character-selection plates are locally processed duotone derivatives of classical sculpture photographs sourced from Wikimedia Commons. Each image remains a complete museum photograph; no figure anatomy was generated or altered.

| Local asset | Source work | Source file | License/source |
|---|---|---|---|
| `athena.webp` | Athena Giustiniani | `Athena_Giustiniani,_Vatican_Museums.jpg` | Wikimedia Commons source page |
| `ares.webp` | Ares Borghese | `Arès_Borghèse_-_Musée_du_Louvre_AGER_Ma_866_;_MR_65_;_N_819.jpg` | Wikimedia Commons source page |
| `apollo.webp` | Apollo Belvedere | `Apollo_del_Belvedere.jpg` | Wikimedia Commons source page |
| `antinous.webp` | Capitoline Antinous | `Capitoline_Antinous_Musei_Capitolini_MC741_n2.jpg` | Wikimedia Commons source page |
| `meleager.webp` | Meleager | `Meleager_Pio-Clementino_Inv490.jpg` | Wikimedia Commons source page |
| `hercules.webp` | Farnese Hercules | `Herakles_Farnese_MAN_Napoli_Inv6001_n01.jpg` | Wikimedia Commons source page |

Processing performed locally for the JRC XIV website: resize, monochrome conversion, contrast normalization, and a shared bronze/ivory duotone grade.

## Arena Background

`/assets/arena-pula-wide.webp` and `/assets/arena-pula-mobile.webp` are locally cropped and color-graded derivatives of **"Anfiteatro de Pula, Croacia, 2017-04-16, DD 01-06 PAN"** by Diego Delso.

- Source: https://commons.wikimedia.org/wiki/File:Anfiteatro_de_Pula,_Croacia,_2017-04-16,_DD_01-06_PAN.jpg
- License: CC BY-SA 4.0
- License URL: https://creativecommons.org/licenses/by-sa/4.0
- Local processing: responsive crops, resize, desaturation, contrast adjustment, brightness adjustment, and restrained warm color grade.
